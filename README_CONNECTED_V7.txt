ชุด v7 แก้ปัญหา “ลูกค้า / สินค้า / รายการผ่อน ไม่เชื่อมกัน และกดเพิ่มไม่ได้”

สิ่งที่แก้ในหน้าเว็บหลังบ้าน:
- โหลดตามลำดับ ลูกค้า -> สินค้า -> บัญชีรับเงิน -> รายการผ่อน เพื่อไม่ให้ dropdown ว่างเพราะโหลดพร้อมกัน
- เมื่อเพิ่มลูกค้า ระบบรีเฟรช dropdown ลูกค้าในสินค้าและรายการผ่อนทันที
- สินค้าผูกลูกค้าได้ตามปกติ
- ถ้าสินค้ายังไม่ผูกลูกค้า ตอนสร้างรายการผ่อนสามารถเลือกจากลูกค้าที่มีอยู่ได้ และตอนกดบันทึกจะผูกกลับไปที่สินค้าให้อัตโนมัติ
- รายการผ่อนจะบันทึก customer_id และ product_id พร้อมกัน
- เมื่อสร้างรายการผ่อน ระบบปรับสินค้าเป็น “ติดผ่อน” และเปิดแสดงบนเว็บ
- trigger ฐานข้อมูลช่วยซิงก์สถานะและความสัมพันธ์ของสินค้า/ลูกค้า/รายการผ่อน
- มีข้อความ error ชัดเจนขึ้น

ติดตั้ง:
1) รัน 14_เชื่อมลูกค้า_สินค้า_รายการผ่อน_อัตโนมัติ.sql ใน Supabase 1 ครั้ง
2) Deploy ZIP v7 ขึ้น Netlify
